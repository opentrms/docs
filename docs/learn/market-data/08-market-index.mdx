In this walkthrough we'll see how a market curve is defined, and what it depends on, in the OpenTRMS Workbench.

The Curve Viewer showed a curve. The Market Index Manager is where that curve is defined in the first place.

Indexes are catalogued by type. Discount curves, overnight index curves, and composites built from others, each with its own currency.

An index carries metadata rather than numbers. The market it belongs to, the group it sits in, and how values between published points are interpolated.

Holiday calendars attach here, which is how a curve knows which days are good business days for the currency it prices.

Dependencies are the interesting part. A composite index is built from others, so changing one of those changes everything downstream of it.

New index adds a definition to the catalogue. Once it exists and has grid point data published against it, it becomes selectable in the Curve Viewer and usable by valuations.
