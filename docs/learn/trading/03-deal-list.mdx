In this walkthrough we'll find a deal in the blotter, and open it for a closer look, in the OpenTRMS Workbench.

The Deal List is the blotter — every trade the system holds, whatever the product. It opens showing all of them.

The filters across the top narrow the list down. They combine, so you can work from a broad view to a precise one without losing your place.

Filter by asset class to see only the fixed income trades. The list updates in place, and the filter stays visible so you always know what you are looking at.

Any column can also group the rows. Grouping by status collects the deals into buckets, each showing how many it holds.

Groups open expanded. Collapse one to see just the summary line, which is the quickest way to read totals across a large blotter.

The same control opens it again, and the grouping can be changed or cleared whenever you like.

Opening a deal brings up its own panel beside the list, so you keep the blotter and the detail on screen together.

And when you already know what you are after, universal search reaches the same deal directly. A counterparty name is usually enough.
